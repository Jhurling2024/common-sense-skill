# Contributing

Bug reports and design critiques are welcome. Please include the actual missed outcome, environment, observed evidence, simplest alternative, risk impact, and a proposed reproducible test case. Avoid private credentials, unpublished user chats, personal details and project-specific secrets.

For changes to decision rules, include a relevant `tests/evaluation-cases.json` scenario and describe the failure of the previous behavior. Do not weaken approval gates or evidence classification to make a benchmark pass.

By contributing, you agree to release your contributions under the repository MIT license. Code review and merges require maintainer approval.
