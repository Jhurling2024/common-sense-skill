# Practical-Judgment Correction Note

1. What outcome did the user actually need?
2. What did the agent do, claim, overlook or unnecessarily complicate?
3. Which simpler supported option existed, if any?
4. What evidence distinguishes the actual problem from a plausible story?
5. What constraints or prior decisions were ignored?
6. What one regression scenario reproduces the oversight?
7. What is the smallest reviewable correction? (propose, do not auto-apply)
8. Which owner/reviewer approves this skill change?
